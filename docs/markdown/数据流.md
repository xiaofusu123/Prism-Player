# PrismPlayer 数据流文档

> 基于项目实际架构，最后更新：2026-06-08

---

## 1. 整体数据流向

项目采用分层架构，数据从 UI 层逐层向下传递到 Engine 层处理，结果逐层向上回调。

```mermaid
sequenceDiagram
    participant UI as UI 层<br/>(Flutter - ui/)
    participant FFI as FFI 层<br/>(ui/lib/ffi/)
    participant SVC as Service 层<br/>(client/service/)
    participant BIZ as Business 层<br/>(av_sync + network)
    participant ENG as Engine 层<br/>(Audio/Video)
    participant ADP as Adapter 层<br/>(File/DB/Net)

    Note over UI: 用户操作
    UI->>FFI: 1. 点击登录
    FFI->>SVC: 2. login(user, pass)
    SVC->>BIZ: 3. 验证账号
    BIZ->>ADP: 4. DBAdapter 查询 SQLite
    ADP-->>BIZ: 5. 返回 Token
    BIZ-->>SVC: 6. 验证通过
    SVC-->>FFI: 7. 登录成功
    FFI-->>UI: 8. 跳转主页

    UI->>FFI: 9. 加入房间 123
    FFI->>SVC: 10. joinRoom(123)
    SVC->>BIZ: 11. 建立 WebSocket
    BIZ->>BIZ: 12. ixwebsocket 连接服务器
    BIZ-->>SVC: 13. 服务器通知: 正在播放 A

    SVC->>BIZ: 14. 启动 AV 同步会话
    BIZ->>ENG: 15. commandOpen(A)
    ENG->>ADP: 16. FileAdapter 读取文件

    Note over ENG: FFmpeg 解封装 + 解码
    ENG->>ENG: 17a. 视频: AVFrame to Vulkan Texture
    ENG->>ENG: 17b. 音频: PCM to WASAPI 设备

    ENG-->>BIZ: 18. AV Sync 校准 (漂移计算)
    BIZ-->>SVC: 19. onFramePresented(TextureID)
    SVC-->>FFI: 20. 通知 UI 更新
    FFI-->>UI: 21. 渲染纹理 Handle
```

## 2. 播放控制数据流

```mermaid
sequenceDiagram
    participant UI as UI 层
    participant FFI as FFI 层
    participant SVC as Service 层
    participant BIZ as Business 层
    participant ENG as Engine 层

    UI->>FFI: 播放 / 暂停 / Seek
    FFI->>SVC: control(cmd)
    SVC->>BIZ: AV Sync 状态更新
    BIZ->>ENG: AudioEngine::pause()
    BIZ->>ENG: VideoEngine::seek(pts, mode)
    ENG-->>BIZ: AudioSyncInfo 返回
    ENG-->>BIZ: VideoSyncInfo 返回
    ENG-->>BIZ: RenderMetadata 返回
    BIZ-->>SVC: 帧就绪
    SVC-->>FFI: 回调
    FFI-->>UI: 刷新画面
```

## 3. Server 端数据流

```mermaid
sequenceDiagram
    participant CLIENT as Client
    participant NET as Network 层<br/>(ASIO + WS)
    participant BIZ as Business 层
    participant ADP as Adapter 层
    participant DB as MySQL

    CLIENT->>NET: WebSocket 连接
    NET->>BIZ: 房间管理
    BIZ->>ADP: 数据库操作
    ADP->>DB: SQL 查询 / 写入
    DB-->>ADP: 结果
    ADP-->>BIZ: 返回
    BIZ-->>NET: 房间状态
    NET-->>CLIENT: 消息广播
```

## 4. 层级职责一览

| 层级 | 目录 | 状态 | 职责 |
|------|------|------|------|
| **UI 层** | ui/ | Flutter 项目已初始化 | Flutter 界面、用户交互 |
| **FFI 层** | ui/lib/ffi/ | FFI 桥接已创建 | Dart to C++ 桥接 |
| **Service 层** | client/service/\ | C API完整实现(27个API) | API 门面，组合业务功能 |
| **Business 层** | client/business/\ | av_sync(完整实现) + network(占位) | AV 同步算法、网络通信 |
| **Engine 层** | client/engine/\ | 抽象接口+工厂骨架完成 | FFmpeg 解码 + Vulkan/WASAPI 渲染 |
| **Adapter 层** | client/adapter/\ | 框架已搭好，待实现 | 文件/数据库/网络基础设施 |
