# PrismPlayer 项目架构文档

> 基于项目实际代码，最后更新：2026-06-08

---

## 1. 总体架构

项目分为 **Client**（客户端）和 **Server**（服务端）两大部分，Client 内部采用六层分层架构。

```
UI 层 (Flutter)      ui/
    |
FFI 层                 ui/lib/ffi/          Dart <-> C++ 桥接（Flutter 项目内）
    |
Service 层            client/service/        API 门面
    |
Business 层           client/business/       AV Sync + Network
    |
Engine 层             client/engine/          FFmpeg + Vulkan + WASAPI
    |
Adapter 层            client/adapter/         File / DB / Network
```

---

## 2. Client 分层详解

### 2.1 UI 层 — `ui/` (Flutter 项目)

| 组件 | 说明 |
|------|------|
| Login Page | 用户登录/注册界面 |
| Room List | 房间列表，浏览和加入房间 |
| Player UI | 播放器主界面，视频渲染区域 + 控制栏 |
| File Sharing UI | 文件分享界面 |

- **开发语言**：Dart + Flutter (3.44.0)
- **当前状态**：Flutter 项目已初始化（含 Android/iOS/Windows/macOS/Linux/Web 全平台脚手架），业务 UI 页面待开发
- **负责人**：梁兴邦

### 2.2 FFI 层 — `ui/lib/ffi/`

Dart 与 C++ 之间的桥接层：

- Dart FFI Bindings：Dart 侧调用 C ABI 导出函数
- C 函数导出：C++ 侧通过 `extern "C"` 暴露接口
- Dart Isolate 通信：避免阻塞 UI 线程

**当前状态**：FFI 桥接文件 `ffi_bridge.dart` 已创建，待完善具体绑定。

### 2.3 Service 层 — `client/service/`

API 门面层，将 Business 层的原子功能组合为面向外部的统一接口。

| 职责 | 说明 |
|------|------|
| 对外 API | 供 UI 层（通过 FFI）和二次开发调用 |
| 功能组合 | 将 AV Sync、网络通信组合为场景化接口 |
| 依赖 | `client-av_sync`、`client-network` |

- **构建产物**：动态库 (`client-service`)
- **当前状态**：**完整实现**（Player.h 27个C API + Types.h 完整类型系统 + PlayerImpl 内部实现 + IServiceNetwork 接口）
- **负责人**：邓志鸿（AV Sync）+ 吴圹钛（Network）

### 2.4 Business 层 — `client/business/`

业务逻辑核心，分为两个子模块：

#### Module A: AV Sync（音视频同步）

| 组件 | 说明 |
|------|------|
| PlaybackStateMachine | 播放状态机（播放/暂停/停止/Seek） |
| SyncAlgorithm | 音视频同步算法，音画漂移计算 |
| CommandDispatcher | 向 Engine 层发送播放指令 |
| EngineObserver | 接收 Engine 层回传的帧状态 |

- **依赖**：Engine 层接口
- **负责人**：邓志鸿（AV Sync）+ 吴圹钛（Network）

#### Module B: Network（网络通信）

| 组件 | 说明 |
|------|------|
| SignalingClient | WebSocket 信令客户端（ixwebsocket） |
| RoomManager | 房间加入/离开管理 |
| AccountManager | 账号认证管理 |
| FileTransferManager | 文件传输管理 |
| P2PConnectionManager | P2P 直连管理 |

- **依赖**：ASIO、ixwebsocket
- **负责人**：吴圹钛

### 2.5 Engine 层 — `client/engine/` 【最完善层】

使用工厂模式创建平台特定的音视频引擎：

| 模块 | 库/技术 | 说明 |
|------|---------|------|
| FFmpeg 模块 | FFmpeg | 解封装 (Demuxer)、视频解码、音频解码 |
| Vulkan 模块 | Vulkan SDK, GLFW, GLM | 渲染管线、纹理上传、Draw Calls |
| Audio 模块 | WASAPI (Windows), SoundTouch | PCM 音频输出、变速变调 |
| 计划扩展 | AAudio (Android), AudioUnit (iOS) | 跨平台音频 |

**核心类关系**：

```
AudioEngineFactory          VideoEngineFactory
       |                           |
       v                           v
AudioEngine (抽象)          VideoEngine (抽象)
       |                           |
       v                           v
AudioEngineWasapiShared     VideoEngineVulkan
(WASAPI 共享模式实现)        (Vulkan 渲染实现)
```

| 接口 | 头文件 | 关键方法 |
|------|--------|----------|
| `AudioEngine` | `engine/include/AudioEngine.h` | `init()`, `play()`, `pause()`, `close()`, `set_play_speed()`, `seek()`, `get_sync_info()` |
| `VideoEngine` | `engine/include/VideoEngine.h` | `init()`, `play()`, `pause()`, `close()`, `set_play_speed(float)`, `seek()`, `get_sync_info()`, `get_render_result()` |
| `AudioEngineFactory` | `engine/include/AudioEngineFactory.h` | `create_audio_engine()` |
| `VideoEngineFactory` | `engine/include/VideoEngineFactory.h` | `create_video_engine()` |

- **构建产物**：动态库 (`client-engine`)
- **当前状态**：抽象接口和工厂已定义，WASAPI/Vulkan 实现骨架已创建，解码模块待实现
- **负责人**：周炎杰（解码）、整体架构

### 2.6 Adapter 层 — `client/adapter/`

基础设施静态库，为上层提供平台抽象：

| 适配器 | 用途 |
|--------|------|
| FileAdapter | 本地文件读写 (MP4, MKV, MP3, FLAC 等) |
| DBAdapter | SQLite 数据库操作 |
| NetworkAdapter | HTTP / WebSocket 网络请求 |
| ConfigAdapter | JSON 配置文件读写 |
| CryptoAdapter | 密码哈希 (OpenSSL) |

- **构建产物**：静态库 (`client-adapter`)
- **当前状态**：框架已搭好，代码待编写
- **负责人**：辜垂沛

## 3. Server 架构 — `Prism-server`

目标运行平台：**Ubuntu (Linux)**

| 层级 | 目录 | 职责 |
|------|------|------|
| Network | `server/network/` | WebSocket 服务端、HTTP API (ASIO + ixwebsocket) |
| Business | `server/business/` | 房间管理、用户认证、消息转发 |
| Adapter | `server/adapter/` | MySQL 数据库操作、文件存储、配置管理 |
