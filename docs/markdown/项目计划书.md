## 1. 项目概述

**项目名称**：PrismPlayer（棱镜播放器）

**项目内容**：开发一款跨平台音视频播放器，支持本地播放和联机同步播放。

**运行平台**：

| 端 | 平台 | 系统 |
|----|------|------|
| 客户端 | Windows x64 | 26H2 |
| 客户端 | Android | — |
| 客户端 | iOS | — |
| 服务端 | Linux | Ubuntu |

## 5. 架构分层

项目总体分为 **六层**：

```
1. 表示层 (UI)          — Flutter / Dart
2. FFI 桥接层           — Dart ↔ C++ 桥接（`ui/lib/ffi/`）【Flutter 项目内】
3. 服务层 (Service)      — C API 门面 【C API已实现】
4. 业务层 (Business)     — AV Sync 已实现 + Network 占位
5. 引擎层 (Engine)       — FFmpeg + Vulkan + WASAPI 【最完善层】
6. 适配器层 (Adapter)    — 文件、数据库、网络操作
```

## 7. 项目文件结构

```
PrismPlayer/
├── client/                  # 客户端 (动态库)
│   ├── adapter/             # 适配器层（静态库）
│   │   ├── include/         # 公开接口
│   │   ├── internal/            # 平台实现
│   │   └── src/             # 源文件
│   ├── business/            # 业务层
│   │   ├── av_sync/         # 音视频同步模块
│   │   └── network/         # 网络通信模块
│   ├── common/              # 公共头文件
│   ├── engine/              # 引擎层（最完善）
│   │   ├── include/         # AudioEngine, VideoEngine 等抽象接口
│   │   ├── internal/            # WASAPI, Vulkan 平台实现
│   │   └── src/
│   ├── service/             # 服务层 (FFI 门面)
│   │   ├── include/
│   │   ├── internal/
│   │   └── src/
│
├── ui/                     # Flutter 项目（含 FFI 桥接）
├── server/                  # 服务端 (可执行文件)
│   ├── adapter/
│   ├── business/
│   ├── network/
│   └── main.cpp             # 入口（占位）
├── vendor/                  # 自定义 C++ 库
│   ├── threadpool/          # 线程池
│   └── memorypool/          # 内存池
├── test/                    # 单元测试
├── docs/                   # 项目文档
├── practice/                # 试验代码
├── build/                   # 构建输出
├── CMakeLists.txt           # 根 CMake
├── CMakePresets.json        # CMake 预设
├── vcpkg.json               # vcpkg 依赖清单
├── build.bat                # Windows 构建脚本
└── build.sh                 # Linux 构建脚本
```
